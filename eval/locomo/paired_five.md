## 过程账(事故与成本)

1. **provider 污染返工(约 78 题次作废)**:评测首小时用户真 config 默认 provider 被切到 minimax,runner 只钉了温度/effort 没钉 active_provider,整批答题悄悄换了模型。发现后剔除全部污染账行,runner 补钉 provider(本批 commit 内)。
2. **主树 exe 疑云返工(约 61 题次重跑)**:协调人报主树构建产物真 console 起手即退(0xC0000409),稳妥起见本批换评测自建 exe(v0.26.196 源码),主树 exe 时期的 54 条 ok 结果剔除重跑。
3. **环境收割与堆损坏假失败**:后台任务被环境每小时收割一次(共 5 次),其中一次留下孤儿 exe 与新进程踩踏同一 home,产生 78 笔 exit=3221225794(堆损坏,wall 0.0s)假失败行,已全部剔除未计入任何统计。
4. **token 成本(逐题末次汇总行口径,含重试)**:本批有效烧账 A 五场 11.46M / B 五场 5.25M / A temporal 2.15M / B temporal 3.40M input,合计约 22.3M input + 0.17M output;A 态占 2/3——空推理重试是成本大头。复用的在档基线(首批 2 场)另约 5.4M input。
