# LoCoMo-MC10 E2 复跑(记忆幻觉根治单:A+B 两刀后 B 态复测,A 态复用五场基线)

口径:与五场终版(`paired_five.md`)同题集(conv-26/41/43/47/49,seed 20260903,五类各 10)、同模型(ccmoon/gpt-5.6-sol,温度 0,推理档 medium)、同判分(扰动后 correct_choice_index)。**A 态逐题账原样复用五场基线(e2_per_question_A_t2.json,拷贝为 _A_r1)——A=memory off,注入侧改动不触该路径**;B 态用本批自建 exe(相关性分级 + 包裹式护栏两刀,措辞走 20 题快测定形的硬指令档)。

两刀形状:A 刀=检索命中按"同句实质匹配"分级(词组词边界同行 + 锚实体同行;弱档垫尾 + 段头 [弱相关] 标注,头部信息行如实报"末 M 条弱相关");B 刀=护栏升级为硬指令——"回答所问必须有一条记忆直接陈述该事实,没有任何条目直接陈述时答案就是'不知道'"(头部 + 段尾包裹)。

快测(20 题 adversarial 子集,B 态单跑):裸底 A 幻觉 0.500;旧 B(五场终版话术)0.800;软措辞(变体 A)0.400;硬指令(变体 B)**0.150**——择硬指令档进终验。

账:e2_per_question_A/B_r1.json(同 suffix 双态);配对口径 = 同 qid 两态都有完成账(A 完成 227、B 完成 247、配对 226)。失败/判不出不计入分母,只报计数。

## 分级的诚实话(判据限度)

词法分级在 LoCoMo adversarial 上分不开"话题沾边"与"真证据"(基准的设计即如此:干扰项就是真对话里的话)。终版分级只把 8~14% 的注入条目标成弱档——本批的主要杠杆是 B 刀话术(硬指令 + 包裹式标注 + 头部如实报数),分级负责的是诚实传递不确定性(弱档垫尾 + 标注)与单实体问法不误伤(门槛随问题词组数收缩)。C 档(问题侧预筛)未启用:快测与终验均已过线,值不回多一轮请求的票价。
