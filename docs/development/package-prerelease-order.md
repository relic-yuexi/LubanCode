# Package 数字预发布号比较合同

合法数字预发布标识符不限 int64。旧 `CompareSemVer` 把字符逐位累进 int64，超过上限便溢出，兼容范围也会跟着误判。

本笔只修共用比较器。已解析的数字标识符无前导零，先比长度，再比同长字符串，即得原数值顺序。不缩 parser 接受面，不复制算法，不动主、次、补丁版本字段、字母段和构建元数据语义。CLI 与随后 SDK 清单分析都沿这一份比较器。

输入、结果仍为同步值，无 Session、文件访问、后台任务或关闭责任。本笔不迁 Package owner，不接公开清单接口，不宣称整包可挂载或可信。

原 `test_package_manifest.cpp` 保 15 CASE 与原全部断言，在原比较与范围两册追加超 int64、更多位、相等、反序和范围匹配。三平台 CLI 用真实 source-filter 单独跑原册，门核唯一登记、实际命令、15 册成功、非零断言；保存源摘要、JUnit、LastTest 和失败原件。全量原门照跑。

本地只做静读、纯 Python 和文档检查。configure、编译、CTest、项目原生进程均交远端 CI。现私有基线的 Windows Atomic 夹具修件须正常纳入，新头另验，旧失败证据不改。
