# SDK 显式 Skills 合同

本批尚未验收。公开入口为 `SessionOptions::skills`、`skills::v1::Selection` 与
`Session::DescribeSkills()`；公开值只含标准库类型。宿主给一处绝对目录和精确选名，
省略便关闭。SDK 不沿 HOME、cwd 或发行目录自动发现技能。

每场只扫一次。同份受限 SKILL.md 字节生成元数据和 SHA-256，再生成提示、工具和
按值清单。必选件缺失、坏声明、重名或同名 `skill` 工具拒启。扫描和读取收固定帽：
根一级条目 4096、候选及选名各 128、全文及单次附件各 1 MiB、扫描累计 16 MiB、
frontmatter 16 KiB、提示 64 KiB、持久计划 256 KiB。帽按实际读取字节算。

正文按指纹拒漂移。附件沿现有 CLI 按需读当前文件，不存快照，不自动执行脚本。
SDK 的附件口拒读文件名为 SKILL.md 的材料，也拒任一所选正文的符号链接、硬链接
别名；正文只从选名入口读。名单外正文的异名硬链接不在指纹保证内，仍按 live 材料读。
路径仍须落在冻结真实目录内。这些检查不构成文件系统沙箱，也不消除并发换树竞态。

Session 持冻结清单；本场 registry 持 SkillTool 和严格读取策略。MCP 装齐后冻结真实
wire 名，再算 `requires-tools` 缺口。缺依赖回 `capability_unavailable`，不自动挂工具。
不同 Session 不共用可变计划，不增线程。Close 沿共有执行对象停接、取消、join，
封会话账后释放 Agent、工具、MCP、后端和文件。闭场查询只交值快照。

冻结计划存 `sdk-skills-plan.json`，摘要记进 V3 system 的 `hostBindings.skills`。
新场拿独占锁后、首行 system 之前落计划。同 ID 恢复先在 SDK 检查声明、计划、
正文指纹，再准备候选工具；拿锁后复验存档和旧史尾 seq/hash，之后才续卷和写审批。
开场参加者只传中立值；门内不扫描技能、不跑工厂、不连 MCP 或网络。

恢复从已验有效 root 初始化正文、设置版本和绑定；不重复追加技能段。显式替换用户
提示才走原三步 system 转移，绑定沿有效根继承。坏计划、绑定缺口、来源水位变化、
提示采用失败均拒启；旧档无计划只准关闭 Skills。附件变化照 live read 放行。
计划文件和日志不是跨文件事务；单边残留不算成功采用，恢复不能倒推或补写掩盖。

首笔不接 preload、Package、热重载、安装命令或录制起草。CLI 五层发现和宽容解析
保留旧路。验收走远端三平台：安装消费者只用公开 SDK，真跑正文和 live 附件，核
指纹与链接绕路、超帽、坏声明、缺依赖、四场重叠隔离、关闭与同 ID 恢复。
本地不 configure、编译、CTest 或运行原生程序。
