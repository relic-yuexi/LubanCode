# SDK 当前模块组合验收

本笔只合私有候选、解相交处、收同一新头证据。各模块继续沿原公开入口、稳定 owner 与 Close 合同；SDK、CLI、AppServer 共用原运行栈。公开后台 Job、SPI 注册、身份接线与网络服务另笔，不能把中立 Job 启动修件算成公开后台功能。

解决冲突只取各笔已审入口与门的并集。Package 两 CPP 与 Lua 共用核心各归原唯一 owner；SDK 测试只加合同列明的中立源，不放开递归宿主 include。Action/Lua/Recovery 相交处保持同一 SessionExecution 与 opening lock；不再养一份 Agent、审批表或恢复器。

预计 focused 34 来源、ASan 39 必需来源、安装消费 25 册，以最终真实登记复核。各笔原 source roster、断言、取消/Close 闸、预算和进程册不得删减。Job 原16册与新增6册共用 source resource locks。Windows 两次实际系统调用分别记32与5或32；长路径两册四份独占 root 必须各自清场。

原生只走远端：三平台组合全量、SDK-only testing OFF/ON、六份安装消费与 focused、Worker/Runner 安装和移位、九份真实 File API 图、必需 ASan。原件核实际 checkout、source/merge 同树、完整 argv 与 JUnit；required 源实跑非零。失败先留原件再改，不把父笔绿或局部绿写成组合通过。

完整 argv 门统一核每份 focused 与每项 ASan required 来源：实际 LastTest 中只能有一行 Command，路径与参数须和唯一登记逐项相同。仅把 Windows 路径分隔符归一，不折大小写、不改工作目录、不省额外参数。纯数据反例须拒绝同名异目录二进制、额外 source/case 筛子、丢失或重复 Command。原模块专门册数、路径及标记门照留。

关场仍先停止准入并请求取消，等主轮、真实 worker/进程与 capture 退场，单写者收确认账后封卷；错账和未知态保留。可信回调不理取消时等真实返回，不许诺硬截止。这里只核现有模块相容，不补 Detached、热卸载或远端 outbox。

本地只读、纯数据门、文档及静核；不 configure、编译、CTest 或运行原生。每次共享功能分支合入仍待该笔确认，最终合 main 前重验最终组合头。旧红账留存，不倒填历史。
