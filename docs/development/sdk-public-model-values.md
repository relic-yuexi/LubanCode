# SDK 共用模型与操作值

这片先解公开头互引。旧 `core.hpp` 定义模型、Backend、Connection 和操作值；
Managed 文本入口也要用它们。将原声明逐字移入 `model.hpp`、`operations.hpp`，
core 继续包含两头，旧 include 和命名不变，不添第二套值或转换层。

两头只依赖公开 API 与标准库。模型请求和答复各自持值；Backend 仍由开场
选项独占，Connection 仍按值传入。操作回执、快照不持 Agent、Writer 或宿主
回调。搬头不改关场、调用次序、字段顺序、默认值或错误。

安装检查须登记两头，核安装字节与当前源码，再由真实安装消费者编译。
先存每份可读安装原件，再读源码、核 presence；缺件、读取或复制失败留失败清单。
证据目录本身无法写入时，命令仍报错，不能承诺原件必能落盘。
首片不新增 Managed Submit、Run 或恢复空入口。后续文本会话在同一执行栈
采用这些值；具体授权与派发另依短合同实现。本地只核源码和纯检查，三平台
编译、安装消费与原生仍交远端 CI。
