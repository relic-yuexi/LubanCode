# SDK 五项用量与来源短合同

开工基线：#348 实际合并 c613f195，源码树 a4e8b943。三平台全量 803/801/804、SDK 双配置 73/71、九套安装消费与 ASan 180 来源/1994 案均已收齐。#348 只交内部用量快照，不交下面这份公开合同。新增公开能力仍在草稿 #349 验收，基线证据不能拿来替它记通过。

公开五项：普通输入、总输出、缓存读取、缓存写入、输出推理。旧 Usage 两项与 ModelReply 聚合前缀保住；同源 C++ 接口，不许承诺旧 DLL ABI。值与字段在场、有效性、来源、原数、异常相随；明确零、缺项、错型、溢出分别记。新增来源材料用标准库数据类型，公开头不带 JSON、渠道或 Gateway。

宿主 Backend 拥有 Generate 返回值。四家真实 Connection 拥有 wire 观察。每次物理请求交给采样 owner，数字、材料、真实响应号一起进快照、assembler、SampleResult 和报告。宿主与 wire 不能生成 provider 响应号；ID-only 回复也须有非终态材料，不假造 usage。状态、政策和后续持久回执各有 owner，不让材料 helper 偷改成功、审批或写回。

先交返回数字，再验正文和取消。规范字段在场便优先，零与错型都不能让别名偷换；矛盾两份原材料都留。加减逐步核 int64，不能绕回或截零。超界数字字面量与解析失败须先留事实，不能只保 DOM 成功那半边。字段或材料无从完整恢复，点明未知，不能让旧数字槽冒充本帧有效报告。

CLI 角色账同守这道数界。累计溢出留前缀，另记未知；显示不能印作精确总数，后续正常报告不能抹掉缺口。输入、输出、耗时各自记，推理不再加到输出；角色分账，清场一并重置。

整轮统计也核五项累计、每步完整输入和最后投影。不可表示就递未知，命中率不能拿残余数字算精确百分比。CLI 与 PostTurn 同用这份裁定，逐步原数不改；明确零仍与未知分开。

流式同字段覆盖，不逐帧相加；Anthropic 缺项留前值，新 message 清旧账。跨请求汇总按字段记覆盖和异常，不能靠全局 OR 或非零猜在场。五项之外的扩展按命名空间留有界材料。数量、字符串、索引、总字节先准入，才复制；复制、分配、回调失败仍要保住已捕获数字，并让不完整材料关掉精确学习路径。

取消、无效正文、错误终态不抹账，也不交成功终帧。Close 取消、等回调、回收 owner；不等模型时持锁，不把 C++ callback 挂到宿主寿命外。失败持久 ACK 与自动 Memory owner 后续各交一片；这份合同只交事实与来源贯穿，不能代替耐久回执或自动写回。

同 ID 恢复须先在实际开场锁内核用量来源，再发布方案或转移旧 system。不开子 Agent 也不能略过主路检查；子路仍归实际子账与接纳链。材料按恢复预算读，拒绝不改主账、操作账或结果。旧结果缺公开 usage 字段照旧恢复，不能凭空补来源。

验收须用实际公开 SDK Backend、四家 parser/Connection、采样与报告调用路径。旧名单不减；补明确零/缺项、错型规范字段与别名、负数/超界/溢出、ID-only、取消/坏正文/错误后事实、跨帧/跨请求覆盖、分配与回调失败、关闭和恢复边界。Windows/Linux/macOS 同源全量、SDK Lua ON/OFF、移位安装消费、ASan 都收原件；TSan 跳过须直说，不能记绿。禁止本地 CI、configure、构建、原生或 HTTP 验收。

实际分配故障验收另用私有子进程。先在真实 parser 成功路径统计普通分配次数，再重建 parser，逐次打断每处分配。四家流式入口与 Responses 非流式入口都须留下实际次数与等量故障证据；每次保留原始 bad_alloc、五项数字只交一次，不交正文或成功终帧，不冒造精确材料。第一处分配探针与逐点扫查各自留证，不能拿一处分配代替整条路径。公开 SDK 的 owner、关闭与恢复仍须另走实际调用链，parser 子进程不能替它验收。

同一子进程再走真实 OnUsageFacts 与 SDK CaptureAttempt：主路、子路分别逐处打断身份和来源记录分配。数字先入所属总账；异常只交一次，记录不完整，精确学习关门。另一账不沾数，事件 JSON 不补交，不重放 owner 回调。这份证据只管实际 typed owner 准入，不能冒称公开 Session 关闭、恢复或耐久 ACK 已过关。

合同先交，完整实现随后迁入；候选源码不能靠半份公开能力换验收绿灯。全套原件核齐才收口。八步目标继续 Active。

provider JSON 解析另设内部 owner。数字先捕获，DOM 后建立；已挂入容器先登记，再做后续分配。正常返回、重复键替换、解析出错与分配失败都从叶向根清空，不在析构途中申请新内存。保住原 JSON 数型、重复键末值覆盖、严格尾部检查及原异常类型；不给正文另设深度上限，不缩减真实分配失败扫查。DOM 只在解析调用内借读，不能越过 owner 寿命。

远程 sanitizer 验收须逐册核原生执行数，CTest 返回零不足为凭。保住原注册名单与现存 CASE 名；退役 v2 夹具留下空册，便把已跑 V3 恢复案归到对应册，不复活旧写口，不另造重复用例。每册实际命令、非零通过数与编译插桩都收原件。已发现零案的旧轮只能记漏验，不能借它承诺整册通过。

上下文图条归 CLI 显示层。原合同仍是超窗口便打满、占比封顶 100%；先比较整数，再换显示尺度，不能先转成窄整数才截断。size_t 原数超过 int64 时直接印原数，不印成负数。这片只管显示换尺度；主 tracker 累计和上下文估算加法仍须另核，不能借显示修复记作全账过关。

坏帧恢复的占位 DOM 也归内部 owner。只造字段在场的形状，数字仍读先前捕获的原材料，不从占位值补数。原标量覆盖、嵌套字段与重复键顺序照旧；恢复途中分配失败，先前数字不丢、不重放、不补交正文。Anthropic 的 message_start 只在数值检查点清旧账，不能到恢复分配前再清一次。五条坏帧实际 parser 路径逐次拒绝全部普通分配，原十四条首错与七条完整扫查原样保留。

SDK-only 必跑数值探针只在 testing ON 建立，单独可执行目标只编本册、只连实际 runtime；不准入 SDK 库闭包，不安装，不带宿主。共享 API 断言也只准本册进入 SDK 测试目标。开场门核现存二十二案和实际 Close 恢复标记，不能拿旧二十案数裁新册。命令夹具在原期限内等完整完成标记；文件刚建成不算写完，不能借它放行或延长期限。

Chat 正文夹具须带明确 wire 身份，才要求开场事件。重复键末值覆盖与深层扩展两案都核原身份和正文；缺身份的消息不能让 parser 凭空补号。原事件数、子案名与分配扫查保留，修夹具不改产品准入。

上下文卡片的估算加法先核 size_t 数界。总量超界便显示未知，剩余与空闲同样未知；不能绕回小数，也不能让满窗口判断把未知改成零。实测总量独立保留；系统加工具超界，只关掉反推历史。延迟工具是否在场直接查三份分项，不拿可能绕回的和作门槛。原正常输出、原始分项与 CASE 名保留，实际断言归现有 ASan 册。

主 ContextTracker 的完整输入、当前占用及会话缓存累计也先核数界。当前投影不可表示便递未知，保留上一份可表示值作内部前缀，不冒充新实测；后续有效实测或明确估算可重立当前尺。会话累计一旦溢出，未知留到清场，后续正常请求不能补平缺口。最近输入、逐请求比例、状态栏、上下文卡片及下一触发线同认投影；未知不触发旧尺自动压缩。清场重置数字与未知位，原缺测、明确零及异常样本排除规则保留。

统计命中率先核三份输入合计，再核命中分子。不可表示、负命中或命中大过总输入，都递未知。有效比例按整数除余四舍五入，不能先乘 200 或借浮点抹平半分界。会话与 epoch 同用这把尺，原正常值不变。原统计册加入两条实际 ASan 选择器及必跑名单；样本存档、累计总量和费用另迁版本合同，不拿这片比例修正替它们验收。

存档整数先核原 JSON 数型与目标数界，才转入槽位。五项、费用 micros、两份合计须落在 int64 内；版本、请求次数与缓存 epoch 须落在 int 内。越界不截断、不绕回，也不能冒充合法版本或次数。整数可写作 JSON 有符号或无符号数，落在范围内便照旧接收；浮点、字符串和 bool 不偷转。版本仍只认 1，原次数下限、费用与 epoch 的符号规则不改。这片只守读侧窄化；五项合计超界、版本迁移及累计查询随后另交，不能借拒收越界槽位掩掉原数。

样本合计迁入可空投影。五项原数与事件来源不改，完整输入及输入加输出各自核界，推理不再相加。正常档仍写 v1；原数齐全而合计不可表示，写 v2，并在两份合计位置明确写整数或 null。读侧接两代，v2 必带两份投影且逐项核真；v1 缺合计可从原数恢复，超界便迁成 v2，不能丢来源。v1 带伪合计仍拒收。旧 C++ 数字槽保留作前缀，生产消费须走可空投影，不能把未知槽位当零。

实际三条 projector、存档读写、聚合合计、CLI 分账与 insights 查询同迁这份投影。两份合计累计超界留前缀，未知留到换新聚合；CLI 占比和建议不借前缀补精确数字。主账与子账规模独立核界，缺一尺便停相互比较。五项逐桶累计、费用累计、请求计数与其余诊断加法尚待后续合同，不拿合计投影替整份统计验收。

公开用量 JSON 报告同守版本界：合计仍是整数便保住 v1，任一分账递出 null 便写 v2。旧消费者不能拿新可空形态当旧整数合同。

逐桶累计随后迁完。普通输入、缓存读、缓存写、输出、推理及估算费用各核加法，各留上一份可表示前缀，各自递未知；后续合法样本不能抹去缺口。单笔费用已报 estimate_overflow，累计费用也认未知。完整输入和计费规模独立记，不能反过来补五项。缓存明报子桶同样守界，未知桶不进精确比例。空账仍写零，未报价仍守原覆盖口径。

这份迁移须贯通 CLI、JSON 分账、insights 摘要、摘要恢复、工作区总账及 HTML；旧 C++ 聚合前缀保留，消费端必须读投影。可空材料抬到 v2，正常材料保 v1；新 analyzer 版本使旧精确缓存重算。请求、工作量与事件计数另核，不能借 token 桶验收冒称所有整数都已收齐。所有出口与同源远端证据未齐，整份迁移仍记未交付。
