## 夹具边界

每次 `StoreHarness` 创建均申请新根。名称用本次值与递增序号，最终由真实 `create_directory` 的成功回执确认拥有；遇已存在只换候选，其他错误立即报出，不借别人目录，也不先删固定旧根。尝试有界。两测试程序即使先后或同时运行，都不得接受现有目录作为本场根。

目录归夹具，显式关场与异常退场都只清这场已拥有的根。Windows 清场从该根的明确原生扩展路径开始，使递归后代仍在同一 namespace；POSIX 保原路径。扩展拼法只在夹具清场入口使用，不改逻辑 ref、结果 ID、display path 或生产路径函数。实际创建失败、删除错误与删除后仍存在分别记录路径及真实错误。清场失败必须让本案失败，不吞错、不重复清场冒充首次成功。

长路径两子例在最后成功标记前显式清场，打印本场根与清场状态，远端可比两测试程序是否各用各根。其余异常出口由同一拥有者清场。不能扫描、删除或认领别场目录。
