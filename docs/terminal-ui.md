# 终端交互

[文档首页](README.md) · [配置手册](configuration.md) · [架构说明](architecture.md)

## 工作状态

请求发出、首个流事件尚未抵达时，状态行显示耗时与 `Esc` 提示。亮色沿 `Working` / `思考中` 逐字扫过。状态行、待发送区与输入框合在同一帧里重画；动画线程只报状态，不单独抢写终端。动画只在真终端启用；管道与重定向不输出控制序列。

输入框下方常驻 status panel。默认摆确认档、模型、工作目录、Git 分支、context 与 token 用量；工作目录或分支在会话中变了，下一次回到输入框便跟着换。不在 Git 仓库时不摆空分支。字段、顺序与分隔符可在 `config.json` 的 `status_panel` 段定制，详见[配置手册](configuration.md#status_panel)。

## 流式输入与排队

模型工作时，输入框仍可键入。光标停在 `> ` 后面；正文续写位置另行保存，下一笔流式内容到来时先回正文落字，再把光标送回输入框。

按 Enter 后，消息进入输入框上方的待发送区。本轮收尾后，消息依次送出。最多展示最近三条，内部队列不截断。按 `Esc` 会先打断当前轮，已落队消息仍会接着发送。

## 粘贴内容

真终端会开启 bracketed paste。1000 字符以内直接落进输入框，多行仍按原样显示、编辑；超过 1000 字符才收成一枚 `[粘贴内容 N 字符]`。光标仍可在它前后添字；退格碰到这枚占位时，会整段删去。按 Enter 后，占位符展开，提交回显与模型输入都拿到完整原文。Windows Terminal 或 VS Code 若只送原生按键、不送 paste 标记，编辑器也会收齐同一趟粘贴，再按同一阈值展示。

这条路也挡住终端把粘贴内容逐行执行。单行粘贴仍按普通文字显示。管道与重定向不输出 bracketed-paste 控制序列。

## Markdown

流式正文先即时落字。每逢空行，渲染器便收束刚写完的一段，换成标题、粗体、列表、表格或代码块。代码围栏没闭合时暂不切段。长回答就算把早先内容卷出屏幕，后续段落仍能各自起锚，不会因一处失账而整篇露出粗体星号与代码围栏。

## `ask_user`

模型遇到会改变实现方向、又无法从仓库查明的选择时，可调用 `ask_user`。一次可问一至四题；每题给二至四项，可设单选或多选。界面总在末尾补一项“自己填写”。

真终端使用原地选择菜单。单选用 `↑` / `↓` 移动、`Enter` 确认；多选用 `Space` 勾选后再按 `Enter`。`Esc` 取消。

```json
{
  "questions": [
    {
      "header": "发布方式",
      "question": "这次要发正式版还是预发布?",
      "options": [
        { "label": "正式版", "description": "直接供日常安装" },
        { "label": "预发布", "description": "先给测试者试用" }
      ],
      "multi_select": false
    }
  ]
}
```

管道与单发模式不注册这件工具，免得无人可答时进程一直等。

## 工具确认

确认提示认 `y`、`a`、`N`。选 `a` 后可把工具名写进项目 `.lubancode/settings.local.json`。彩色 diff 收起时会连字符与背景属性一道清掉，不留下色块。

`write_file` 与 `edit_file` 的 diff 按路径扩展名给代码着色。新增、删除背景铺在外层；关键字、字符串、数字、注释、类型、函数只换前景色。行末再统一复位，故而 token 换色不会截断绿底或红底。现支持 C/C++、Python、JavaScript/TypeScript、JSON、Shell/PowerShell、Rust 与 Go；不认得的扩展名保持素色。

工具条目与流式输入框共用屏幕改写事务。条目开始时亮黄灯，结束后在原位换成绿灯或红灯；不会把运行态与终态各留一行。事务退场时会立即重建输入框，不等下一段正文来补画。

`todo_write` 首次落计划时显示 `todo_write(N 项)`；同一轮后续改状态时显示 `todo_update(N 项)`。项数不变便抓住原计划块就地更新，只点亮有变化的条目。计划增删项时另起更新块，免得旧块在屏幕中段长高，盖住下方输出。工具协议仍用全量 `items`，会话记录也照常保留每次调用。

## 编辑匹配

`edit_file` 先做字节级精确匹配。失败后依次尝试：

1. 统一 `CRLF`、`LF`、`CR`。
2. 忽略整块统一缩进与行尾空白。

任何一层出现多处候选，且没有显式设置 `replace_all=true`，工具都会拒绝改动并报候选位置。三层都找不到时，结果会要求模型先用 `read_file` 读取最新片段，避免原样反复重试。
