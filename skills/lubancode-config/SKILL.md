# LubanCode 配置与功能

先读 `references/document-map.md`。Skill 工具返回的“技能目录”是基准目录；官方
文档根目录固定为 `<技能目录>/../../docs`。只加载与问题相干的页面，不整库
灌进上下文。

办事时守这几条：

1. 先从文档地图挑一至三页，再向源码、`--help`、`--config` 或测试核实易变事实。
2. 改配置前先读现有文件，只改目标字段；保留未知字段、缩进和用户注释能保则保。
3. 密钥只落本机配置或环境变量，不贴进答话、测试、截图和 Git。
4. 项目级设置不得暗中扩大用户级权限。执行命令、安装依赖、信任 Hook 或原生
   Plugin 前，照现有确认与安全规矩办。
5. 官方 docs 根不存在时，明报安装缺件；可用 `/help`、`/config` 等运行输出
   临时查证，不能凭旧 Skill 内容猜。
