## description

Load a discovered skill (SKILL.md) by name and get its full instructions. A skill is a pre-written set of concrete practices (a house style for some kind of writing, a fixed workflow for a class of tasks, say); when a skill name/description listed in the system prompt matches the task at hand, call this tool to read the instructions in first, then follow them.

## param.name

Name of the skill to load; the same name as listed in the system prompt
