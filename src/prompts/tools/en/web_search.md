## description

Web search; returns a numbered list (title/URL/snippet). Good for the latest news or for finding documentation addresses; once you have a URL, fetch the page body with web_fetch. Jobs that need several rounds of searching and several pages read before summarizing belong to an agent subagent.

## param.query

Search keywords or question

## param.count

How many results you want; omit for the default 5, capped at 10
